A zero-dependency Node.js log aggregator starter generated by Forge.

## Usage

```sh
npm test
npm run bench
cat app.ndjson | node src/cli.js --level warn --json
node src/cli.js --since 2026-01-01T00:00:00Z app.ndjson
```

## Behavior

- Reads NDJSON from stdin or one or more files, streaming line by line.
- Accepts `level`/`severity`, `message`/`msg`/`event`, `timestamp`/`time`/`ts`,
  and `latency_ms`/`latency`/`duration_ms` fields.
- Counts malformed lines instead of crashing.
- Filters by minimum level and optional time window.
- Reports counts and latency min/avg/p50/p95/p99/max.

## Quality gates

- `npm test` — unit and CLI tests
- `npm run test:coverage` — coverage report
- `npm run lint` — syntax checks
- `npm run build` — syntax checks
- `npm run bench` — writes `bench/results.json`

## Design

`src/aggregator.js` is pure and streaming-friendly; `src/cli.js` owns file and
stdin IO. The benchmark parses and aggregates 200k NDJSON records, including
malformed-input and percentile paths.
