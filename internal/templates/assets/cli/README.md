A zero-dependency Node.js CLI starter generated by Forge.

## Usage

```sh
npm test
npm run bench
node src/cli.js --help
printf 'hello world\n' | node src/cli.js
```

## Commands

- `count` (default): count lines, words, and UTF-8 bytes from stdin or files.
- `--json`: emit a machine-readable result.
- `--file <path>`: read one file instead of stdin.

## Quality gates

- `npm test` — unit and CLI tests
- `npm run test:coverage` — coverage report
- `npm run lint` — syntax checks
- `npm run build` — syntax checks
- `npm run bench` — writes `bench/results.json`

## Design

The CLI is a thin shell over pure functions in `src/lib.js`. Parsing, counting,
and formatting are unit-tested without spawning processes; the CLI integration
tests cover exit codes and real stdin/file behavior.
